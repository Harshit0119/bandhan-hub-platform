# 💍 BandhanHub

### Modern SaaS Marketplace for Wedding Vendors & Couples

BandhanHub helps wedding vendors create professional profiles, showcase services, receive inquiries, manage leads, and grow their business online.

Built with scalability, clean architecture, and production-level SaaS practices in mind.

# 🧠 Architecture Highlights

## 🔐 Row Level Security (RLS)
Implemented advanced Supabase RLS policies to ensure:
- Vendors only manage their own data
- Public profiles stay accessible
- Secure inquiry management
- Protected dashboard operations

---

## ⚡ Optimized SaaS Structure
BandhanHub is being built using scalable SaaS patterns:
- Modular dashboard architecture
- Centralized auth context
- Reusable UI system
- Dynamic vendor-based routing
- Database-first architecture
